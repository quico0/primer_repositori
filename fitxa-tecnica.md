# Fitxa tècnica: Creació d'un repositori GitHub i ús de Visual Studio Code

## Objectiu

Crear un compte de GitHub, generar un repositori, clonar-lo amb Visual Studio Code i sincronitzar els canvis.

## Materials

- Ordinador amb connexió a Internet
- Compte de GitHub
- Visual Studio Code
- Git

## Procediment

1. Crear un compte a GitHub.
2. Crear un repositori públic.
3. Crear el fitxer README.md.
4. Copiar l'URL del repositori.
5. Clonar el repositori amb Visual Studio Code.
6. Editar el fitxer README.md.
7. Desar els canvis.
8. Executar git add.
9. Executar git commit.
10. Executar git push.

## Comprovacions

- [ ] El repositori existeix a GitHub.
- [ ] El README.md està actualitzat.
- [ ] Els canvis apareixen a GitHub.

## Incidències i solucions

| Incidència | Solució |
|---|---|
| Error d'autenticació | Tornar a iniciar sessió a GitHub |
| No apareixen els canvis | Executar git push |

## Bloc de codi

```bash
git add .
git commit -m "Afegeix presentació inicial"
git push origin main
```

3. Veure diferències amb git diff.

5. Crear un commit amb git commit.
6. Sincronitzar amb git push.
